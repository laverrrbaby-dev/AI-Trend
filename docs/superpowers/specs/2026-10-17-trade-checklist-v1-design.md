# 交易前 Checklist V1

状态：已确认（2026-10-17）。用户已确认本规格及“以 OKX 预估强平价作为执行退出价”的定义。

## 目标与范围

在现有币圈区域新增「交易前检查」页面，防止账户金额错误、退出位置偏离计划、盈亏比不足时仍然开仓。

用户手动填写、核对并在 OKX 下单。首版不连接交易账户，不执行交易，不包含开仓后记录、持仓追踪和交易建议。

## 固定交易规则

- 平台：OKX；保证金模式：全仓。
- 每笔交易前，交易账户资金固定为 500U。
- 同一账户一次只做一笔交易；开仓前处理上一笔持仓、剩余挂单及资金。
- 初始退出采用强平机制，策略失效条件按触价判断。
- 做多：执行退出价不得高于原计划退出价。
- 做空：执行退出价不得低于原计划退出价。
- 按调整后的执行退出价计算，价格距离盈亏比必须严格大于 1.5。

将 OKX 显示的预估强平价作为“执行退出价”填写和核对。它是检查时的预估值，不代表保证成交价格。

## 页面流程

### 1. 核对账户

填写实际交易账户资金，逐项确认：

- 上一笔持仓已结束。
- 剩余挂单已处理。
- 上一笔剩余资金或盈利已清理，当前资金为 500U。
- 本次选择 OKX 全仓模式。

金额不等于 500U，或任何确认项未完成，均不能通过。

### 2. 写下交易计划

必填：

- 交易品种、做多或做空。
- 交易类型：价格行为 / 趋势交易。
- 参考周期与退出依据。
- 计划开仓价。
- 原计划退出价。
- 计划止盈价。

退出依据填写示例：

- 价格行为：“参考某日的日线最低点，价格为……”
- 趋势交易：“参考某周期的某结构，跌破/突破……代表趋势破坏。”

本版手动填写依据和价格，不自动识别高低点或趋势结构。

### 3. 核对实际下单参数

填写准备在 OKX 使用的杠杆、数量，以及 OKX 显示的预估强平价。

手动确认这些数值与 OKX 当前下单页面一致。无法获取或确认预估强平价时，不通过检查。

系统检查：

| 方向 | 价格关系 | 退出位置限制 |
|---|---|---|
| 做多 | 执行退出价 < 开仓价 < 止盈价 | 执行退出价 ≤ 原计划退出价 < 开仓价 |
| 做空 | 止盈价 < 开仓价 < 执行退出价 | 开仓价 < 原计划退出价 ≤ 执行退出价 |

系统展示：

- 盈利距离 = 止盈价与开仓价之差的绝对值。
- 亏损距离 = 执行退出价与开仓价之差的绝对值。
- 计划盈亏比 = 盈利距离 ÷ 亏损距离。
- 原计划退出价与执行退出价的偏差。

计划盈亏比必须 **> 1.5**。明确标注“按价格距离计算，未扣手续费及资金费”。

### 4. 最终检查结果

所有必填字段有效、系统规则通过、手动确认完成后，显示「检查通过」。

否则显示「检查未通过」，逐项列出具体原因，例如：

- “账户资金为 700U，与固定投入 500U 不符。”
- “做多的预估强平价高于原计划退出价，会提前退出。”
- “盈亏比为 1.50，未满足严格大于 1.5。”

检查通过仅表示填写内容符合规则，不代表系统已核实 OKX 账户，也不代表交易一定盈利。

修改账户资金、交易方向、价格、杠杆或数量后，相关确认失效，必须重新检查；不能继续显示旧的通过结果。

## 保存与重置

- 保存当前检查草稿，刷新页面后可继续。
- 点击「新一笔检查」清空本次填写与勾选，保留固定规则。
- 首版只保存当前检查，不建立交易历史或持仓记录。

## 验收标准

1. 账户填 700U，即使其他项目完成，也不能通过。
2. 做多的执行退出价高于原计划退出价，不能通过；做空反之。
3. 价格方向错误、距离为零、字段缺失，不能通过。
4. 盈亏比等于或小于 1.5，不能通过。
5. 所有规则满足但手动确认未完成，不能通过。
6. 修改关键参数后，旧的通过状态立即失效。
7. 页面始终同时展示原计划退出价、执行退出价及计算后的盈亏比。
